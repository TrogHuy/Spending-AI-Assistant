# Spending Assistant

AI assistant that reads your payment screens, categorizes spending, checks who you are paying, and warns when a payment deserves a second look. Read-only: it never moves money.

Built for the MoMo TechDay 2026 Tech Contest. Topics: AI Assistant, Anti-scam.
